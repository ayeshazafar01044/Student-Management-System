# Student-Management-System

Python Student Management System using Tkinter.

## Features

- Add, update and delete students
- Search students
- Student photos
- Marks and grade management
- Statistics dashboard
- Save and backup student data
- Built with Python and Tkinter

## Technologies Used

- Python
- Tkinter
- Pillow
- JSON
